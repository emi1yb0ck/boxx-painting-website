# Boxx Painting & Pressure Cleaning, Inc. — Website

A static website built with plain HTML, CSS and JavaScript. It has no build step.

## Files
- `index.html`: page content and sections
- `styles.css`: colors, fonts and layout. Brand colors are at the top, under `:root`.
- `script.js`: mobile menu and online estimator. Estimator prices are in `RATES`.
- `images/`: placeholder images. Replace them with real project photos.

## Preview
Open `index.html` in a browser.
